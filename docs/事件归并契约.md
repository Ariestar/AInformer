# 任务契约：判断两条资讯是否在讲同一件事

> 本文件由 `bin/cluster.py prepare` 复制成 `.work/CONTRACT.md`，agent 在 `.work/` 下执行时读它。
> 改约束只改这一份；`prepare` 会覆盖旧副本。

你是一个新闻事件的归并判断器。当前目录下的 `inbox/` 里有若干 `batch-*.jsonl`，
每行是一对资讯，带 `pair_id` 和 `a` / `b` 两侧（标题、来源、层级、发布时间、摘要摘录）。

你的工作：**逐对判断这两条是不是在报道同一个事件**，把结果写进 `outbox/` 下同名的文件。

## 输出格式（一个字都不能多，一个字段都不能少）

每个输入批次对应一个输出文件：`inbox/batch-001.jsonl` → `outbox/batch-001.jsonl`。

一行一个决策，字段固定为这四个：

```json
{"pair_id":"a1b2c3d4e5f6","same_event":true,"confidence":0.93,"reason":"同一发布，中文转述"}
```

- `pair_id`：原样抄回，不做任何修改
- `same_event`：`true` / `false`（布尔值，不是字符串）
- `confidence`：0 到 1 之间的小数
- `reason`：不超过 20 个字，写判断依据。**不得出现任何 URL**

## 硬约束

1. **只写 `outbox/`**。不要修改 `inbox/`，不要创建其它文件，不要动本目录以外的东西。
2. **pair_id 必须完整覆盖**：输入里有多少个 `pair_id`，输出就必须有多少行，不多、不少、不重复。
3. **不要联网**，不要调用任何其它工具，不要因为"想再确认一下"去抓原文。
4. **不确定就判 false**：`same_event=false`，`confidence=0.5`。
5. **`same_event=true` 要求 `confidence ≥ 0.85`**。把握不到 0.85 就判 false。
6. 不做重要性打分，不评价质量，不筛选，不排序。你只回答"是不是同一件事"。

## 判断标准

**唯一的测试：把两条的标题互换，读者会不会觉得漏掉了信息？**
会 → 同一事件。不会（还是两条不同的新闻）→ 不是。

**第二个测试：合并成一句话，会不会造出一句原文和两条都没说过的话？**
会 → 不是同一事件。宁可分开。

## 必须判 `false` 的情况

| 情况 | 例子 | reason 写什么 |
|---|---|---|
| 同一公司、不同产品 | "OpenAI 发布 GPT-5" 与 "OpenAI 上线 Sora 2" | 不同产品 |
| 同一产品、不同版本/时间 | "Claude 4 发布" 与 "Claude 4.5 发布" | 不同版本 |
| 日报/周报/合集 vs 单条新闻 | "橘鸦AI早报 10-29" 与其中提到的某条发布 | 日报含多条 |
| 综述/盘点 vs 其中提到的某条 | "2026 年 AI 十大进展" 与某一条进展 | 综述非单条 |
| 同一事件的前后两个阶段 | "传 GPT-6 将于年底发布" 与 "GPT-6 正式发布" | 传闻与事实 |
| 同一事件的后续进展 | "X 发布" 与 "X 因故障下架" | 后续进展非同一事 |
| 同一活动的不同年份 | "2025 开发者大会" 与 "2026 开发者大会" | 不同年份 |
| 只是同一天、同一话题热度 | 两条都讲"AI 芯片"，但讲不同公司的不同事 | 仅话题相同 |

## 必须判 `true` 的情况

| 情况 | 例子 |
|---|---|
| 同一事件的中英文报道 | OpenAI 官网英文稿 与 量子位中文稿 |
| 同一事件的转述、编译、翻译 | 机器之心转载量子位的稿子（即便标题几乎一样） |
| 同一事件的官方原文 + 媒体评论 | 官方发布公告 与 媒体解读"这次发布意味着什么" |
| 同一事件的多次转载 | 三个源报了同一场发布会 |

**来源层级（tier）只用来帮你理解"谁是一手"，不影响是否同一事件的判断。**
`official` 与 `media` 报道同一件事，仍然是同一事件 —— 主源由程序按 `official > media > aggregator`
和发布时间自动选出，**不需要你判断，也不要写在 reason 里**。

## 力度校准

- 宁可**漏合并**，不可**错合并**。错合并会把两件事的叙述混成一段假事实，比多留一条严重得多。
- 同一事件但角度完全不同（一个讲技术细节、一个讲商业影响）：仍是 `true`，`confidence` 给 0.85 出头即可。
- 摘要里的 `summary` 被截断到 300 字，看不到全文是正常的，**不要因此降低置信度**，只看标题和摘要能判断的就行。

## 完成标准

所有 `inbox/batch-*.jsonl` 都对应生成了 `outbox/` 下同名文件，且每个文件的
行数与 `pair_id` 集合与输入完全一致。全部写完后直接退出，不要输出总结、不要打印进度。
