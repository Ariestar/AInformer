### 一、GitHub Copilot 全局默认策略开始生效，用量指标细化到具体 skill 与 MCP

**分类：产品**

**发生了什么**：GitHub 于 2026-10-22 起逐步执行 9 月宣布的"全局默认"策略，执行窗口持续到 10 月 26 日，不同组织生效日期可能不同。该策略覆盖 Copilot Business 与 Enterprise 上已正式可用（GA）的 Copilot 功能与受支持的客户端能力。同日，Copilot 用量指标 API 开始显示组织自建的自定义 skill、自定义 agent、MCP server、slash command 和插件的**具体名称**，不再统一归入 other / custom。

**为什么重要**：两件事都落在管理员身上。默认策略意味着"不主动关闭就会全员启用"，需要有人做一次显式决策；用量指标细化后，才能算清"哪个 skill 真在被用、哪个 MCP 接了但没人碰"，这是做 AI 投入产出汇报的前提。

**适合谁关注**：Copilot 管理员、研发效能与 IT 治理岗、需要向管理层汇报 AI 使用情况的负责人。

**来源**：2026-10-22 · GitHub Changelog · https://github.blog/changelog/2026-10-22-global-default-for-copilot-features-generally-available ｜ https://github.blog/changelog/2026-10-22-custom-skills-agents-and-mcp-servers-in-usage-metrics-api

### 二、ChatGPT Ads 扩至 26 个新市场，全球覆盖 89 国

**分类：产品**

**发生了什么**：OpenAI 于 2026-10-21 宣布 ChatGPT Ads 新增 26 个国家，全球覆盖达 89 个。新增市场包括阿根廷、智利、哥伦比亚、秘鲁等 14 个拉美国家，以及尼日利亚、南非、塞尔维亚、乌克兰、柬埔寨、孟加拉国、巴基斯坦等。官方称上线八个多月来已有超过 10 万个广告主投放。广告**只出现在 Free 与 Go 套餐**，Plus、Pro、Enterprise 保持无广告；广告与回答分开标注，官方声明广告不影响回答内容。

**为什么重要**：对市场与品牌岗，ChatGPT 成为一个新的投放渠道，且卖点是"用户还在比较选项的对话时刻"；对普通用户，免费版的信息环境开始商业化，读到广告的比例会上升。原文列出的新增市场中不含中国大陆。

**适合谁关注**：市场投放、品牌、电商运营；关注 AI 产品信息环境的产品经理。

**来源**：2026-10-21 · OpenAI · https://openai.com/index/chatgpt-ads-expands-26-new-countries

### 三、OpenAI 前沿模型将进入 Google Cloud Model Garden，可用 GCP 承诺额度抵扣

**分类：行业**

**发生了什么**：OpenAI 与 Google Cloud 于 2026-10-21 宣布合作，将 OpenAI 前沿模型与 Codex 智能体工作流接入 Google Cloud 的 Model Garden，通过 Google Cloud Marketplace 交易；已有 GCP 消费承诺的企业可用承诺额度支付。官方称正式可用（GA）计划在未来数周内上线，目前需申请访问。此外 OpenAI 模型还将进入 Google Antigravity 与 Gemini Agent。OpenAI 明确表示微软仍是其首要云合作伙伴。

**为什么重要**：企业采购路径变了。原本要在"用哪家模型"和"用哪朵云"之间做取舍的团队，现在可以在既有 GCP 承诺内直接买 OpenAI 模型，不必新增采购流程。对已在 GCP 上的企业，这是降低引入门槛的一步。

**适合谁关注**：企业架构师、云采购与 IT 负责人；正在做模型选型或续签云合同的团队。

**来源**：2026-10-21 · OpenAI · https://openai.com/index/openai-models-google-cloud

### 四、《国家信息化"十五五"规划》印发，设"数据跨境流动便利化提升行动"专栏

**分类：风险（合规）**

**发生了什么**：中央网络安全和信息化委员会于 2026-10-23 印发《国家信息化"十五五"规划》，提出到 2030 年的目标，包括适时启动 6G 商用、国家区块链网络基本建成、智能互联网加快布局发展等。总体布局为"建设三个体系、提升五个水平、夯实两个支撑"，部署 10 个方面任务，设 7 个专栏，其中包含**数据跨境流动便利化提升行动**。规划全文与答记者问同日在中国网信网发布。

**为什么重要**：数据跨境这一项与企业做 AI 应用直接相关——只要用到境外模型或境外云，就会碰到数据出境问题，专栏化意味着未来五年会有配套措施落地。这是需要持续跟踪的政策变量，不是本周就要改动作的事。

**适合谁关注**：企业法务与合规、政府事务、使用境外模型或云服务的 IT 负责人；数据中心与算力相关业务。

**来源**：2026-10-23 18:00 · 中国网信网（中央网信办）· https://www.cac.gov.cn/2026-10/23/c_1794509044378569.htm
**旁证**：36氪快讯（未标注发布时间）· 北京日报、新华日报等转载新华社通稿
